# Paramita Frontend Instructions

## Language

- Use English for all project text, including user-facing messages, labels, placeholders, validation messages, notifications, comments, and documentation.
- Do not add Bangla/Bengali letters, words, sentences, or messages anywhere in project source or user interfaces.

## Form Validation and Required Fields

- Show each validation error inline directly below its corresponding input field.
- Keep errors field-specific; do not rely only on a general error summary or toast for input validation.
- Associate each error with its input for accessibility, and mark invalid inputs accordingly.
- Mark required fields with a visible red `*` next to the field label.
- Show the red asterisk only for fields that are actually required by the validation rules.
